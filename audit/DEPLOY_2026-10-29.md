## Not uploaded, and why

- **`rb-studio` (the AI Forge, RB account).** The token used today can't reach the RB account, so the Forge keeps its
  current code. Autopilot already carries approvals and offers the Forge the operator's rules every 10 minutes; the
  Forge just ignores them until its patch is uploaded. Its tests ran against a read-only copy and pass. **To finish:**
  run `./deploy-all.sh --deploy` with a token that also covers the RB account (or set `CF_ACCOUNT_ID` for that one push).
- **`rb-public-content`.** Live is now one bundled file (`e17e0f0b`, uploaded 29 Oct 07:45 UTC, with a new `owner.js`
  for site effects), built outside this repo. It no longer has the separate modules the repo's patches edit, and
  uploading the repo's version would have removed that new work. It was left exactly as it is. What that means today:
  - the Dark Luxury token lock and the luxe motion layer (pull request #7) reach pages through artist-router, rb-radio
    and rb-command, but not through rb-public-content's own CSS;
  - its source should be brought into this repo before the pipeline touches it again.
- **`rb-cloud`.** Patched and tested, but its change only acts once it has a D1 binding named `DB`. It runs Durable
  Objects and a container, so it is best uploaded on its own when that binding is added (`cfworker.py push rb-cloud`).
